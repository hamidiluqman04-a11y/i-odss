# I-ODSS v7 prototype (archived)

The earliest committed version of the FastAPI + vanilla JS prototype
("Initial commit for deployment"). It is kept only for reference and is
**not** part of the running system; the current app is in `backend/` (Django)
and `frontend/` (React). The newer v8 prototype is in `legacy/backend` and
`legacy/frontend`.

Its sample CSV files were identical to `frontend/public/samples/` and were
removed from here, so the v7 pages' "Download" sample links no longer work.
