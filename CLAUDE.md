# Claude Code Project Rules

## Design & Styling Truth
- Always read, reference, and strictly adhere to the `DESIGN.md` file in the project root before writing, modifying, or refactoring any UI components, styling, or layouts.
- Do not invent new color palettes, spacing utilities, or typography rules outside of what is explicitly defined in `DESIGN.md`.
- If a requested UI change conflicts with `DESIGN.md`, flag the conflict to the user before writing code.
